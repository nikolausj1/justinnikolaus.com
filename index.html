This calendar is built from usage records saved on my Mac by Codex and Claude Code, including Claude’s desktop agent sessions. Each square is a day; darker blue means more AI tokens processed. Tokens are the small pieces of text and code an AI reads or writes.

Snapshot through Sep 28, 2026. Refreshed manually. Totals include saved context the AI reuses across requests.

Where the data comes from and how it’s counted

From local logs to this calendar. I built a script that reads the usage numbers these apps save during sessions, removes duplicate records, and groups the totals by day, app, and model using Pacific time. It includes separate responses from subagents. Only summarized usage is published here. Conversations, prompts, and project files stay private.

What the numbers mean. Input is new content sent to the AI; output is what it generates, including reasoning. Cache writes are context saved for later, and cache reads are that context used again. Each reuse contributes to the total. An active day has recorded usage; a blank day has none in the available records. The calendar measures usage volume, not hours worked or finished projects.

Coverage and updates. Cline, Gemini CLI, GitHub Copilot, Kiro, Antigravity, OpenCode were detected without readable token counts. Missing, deleted, or remote-only records aren’t estimated. This page displays a saved snapshot. I refresh it by rerunning the local script, rebuilding the page, and publishing it again. It doesn’t connect to my computer or update automatically when you visit.
