Justin Nikolaus / token activity

A calendar built from usage records saved on my Mac by Codex and Claude Code, including Claude’s desktop agent sessions. Each square represents a day. Tokens are the small pieces of text and code an AI processes; totals include saved context reused across requests.

How it was created: I built local scripts that extract usage numbers from the apps’ session logs, remove duplicate responses and repeated streaming snapshots, and group the results by day, app, and model. The homepage uses a custom calendar; this explorer uses Ben Tossell’s original renderer. Only summarized usage is published. Conversations, prompts, and project files stay private.

How it updates: This is a saved snapshot through Sep 28, 2026. I refresh it by rerunning the scripts on my Mac, rebuilding the page, and publishing it again. Opening this page doesn’t connect to my computer or trigger a refresh. No automatic updates are enabled.

Coverage: Oct 1, 2025 to Sep 28, 2026, using Pacific dates. Codex and Claude Code are included. Other detected apps had no readable token counts. Missing or deleted usage is not estimated.

Cost is a partial list-price estimate: 99.82% of recorded tokens have a matching rate. gpt-5-codex, codex-auto-review have no usable price in this catalog and are excluded from cost, not treated as free. This is not an invoice or subscription spend. Rates come from models.dev; one-hour Claude cache writes follow Anthropic’s cache pricing. Rates reflect the downloaded catalog, not historical invoices.

Counting: Input is new content sent to the AI. Output is what it generates, including reasoning. Cache writes are context saved for later; cache reads are that context used again. Each reuse contributes to the total. Separate subagent responses are included. An active day has recorded usage; a blank day has none in the available records. This measures usage volume, not hours worked or finished projects.
