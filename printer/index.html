The idea

Turning an old printer into a fun weekend project

I found an old thermal printer that had an Ethernet port, so I wondered if I could hook it up to the internet so friends could send me messages that print right on my desk.

How it was made

I started by connecting the Rongta RP820 thermal printer that I found to my network and sending test commands directly from my Mac. Once I got printing to work, I built a cloud-based holding area (a queue) where each incoming message waits safely until the printer is ready for it. This keeps the public website separate from my home network and helps prevent messages from being lost or printed twice. I then moved the print worker, a small program that watches the queue and translates messages into printer commands, to an always-on Windows server in my house. When a new message arrives, the worker retrieves it, sends it to the printer over my local network, and reports whether it printed successfully.

From there, I built the public page, live printer status, moderation, rate limits, duplicate protection, and an emergency pause.

Cloud

Home worker
Node.js running as a Windows service
Printer link
Raw TCP over Ethernet using ESC/POS

Each message is rate-limited, checked, queued once, and accepted only while the printer is reporting that it is healthy.
